# Requirements Archive: v1.0

## v1 Requirements — All Delivered

### Topic Search (FRIS-01)

- [x] **FRIS-01**: User can input a topic (free text, e.g., "AI chips") and time period (quarter/date range) — via TopicSearchService
- [x] **FRIS-02**: System matches topic to GICS sectors/industries using keyword mapping table — via TopicClassifier
- [x] **FRIS-03**: System returns list of relevant US stock tickers with company names and industries — via StockRepository.search_by_industry

### Stock Filtering (FRIS-02)

- [x] **FRIS-04**: Filter by market cap (min/max in USD, or predefined: large/mid/small cap) — via StockFilterService
- [x] **FRIS-05**: Filter by P/E ratio (min/max, handle negative earnings as N/A) — via StockFilterService
- [x] **FRIS-06**: Filter by P/B ratio (min/max, handle negative book value as N/A) — via StockFilterService
- [x] **FRIS-07**: Filter by stock price (min/max in USD) — via StockFilterService
- [x] **FRIS-08**: Filters are combinable (AND logic) — via StockFilterService
- [x] **FRIS-09**: System returns filtered stock count before full data fetch — via StockFilterService.get_filtered_count()

### Earnings Data Fetching (FRIS-03)

- [x] **FRIS-10**: Fetch latest earnings data for each filtered stock (EPS, revenue, earnings date) — via EarningsService
- [x] **FRIS-11**: Fetch company overview data (market cap, P/E, P/B, price, description) — via EarningsService
- [x] **FRIS-12**: Fetch earnings guidance (forward EPS if available) — via EarningsService.get_earnings_guidance()
- [x] **FRIS-13**: Handle missing/incomplete data gracefully (flag as N/A, continue processing) — via StockInfo._display properties
- [x] **FRIS-14**: Support quarterly data (Q1, Q2, Q3, Q4) with year — via EarningsService.get_quarterly_data()

### Business Summary Generation (FRIS-04)

- [x] **FRIS-15**: Generate structured summary covering business model, performance, competitive landscape, risks — via SummarizationService
- [x] **FRIS-16**: Each summary is a separate document (JSON/markdown format) — via StockSummary.to_dict()
- [x] **FRIS-17**: Summary includes: company name, ticker, industry, reporting period, key metrics — via StockSummary dataclass
- [x] **FRIS-18**: LLM prompts include financial context to reduce hallucination — via LLMClient financial context building
- [x] **FRIS-19**: Summaries cite data sources (API provider) — via prompt includes "Source: Yahoo Finance"

### Data Source (FRIS-05)

- [x] **FRIS-20**: Primary data source: Yahoo Finance via yfinance library — via StockRepository (yfinance primary)
- [x] **FRIS-21**: Fallback/supplementary: FMP API (if yfinance coverage gaps) — via StockRepository (FMP fallback)
- [x] **FRIS-22**: Cache financial data locally to reduce API calls — via FundamentalsCache (24hr TTL), PriceCache (1hr TTL)

### Output (FRIS-06)

- [x] **FRIS-23**: Return results as structured JSON (one object per stock) — via StockSummary.to_dict()
- [x] **FRIS-24**: Each result includes: ticker, company_name, industry, period, summary_text, key_metrics — via StockSummary
- [x] **FRIS-25**: Include data freshness timestamp — via generated_at field in StockSummary

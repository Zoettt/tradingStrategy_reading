# Roadmap: Financial Report Interpretation System (FRIS)

## Overview

A pipeline-based system that transforms a user topic query (e.g., "AI chips") plus a time period into structured earnings summaries for relevant US stocks. The system chains topic classification via GICS, stock screening by financial metrics, earnings data fetching from financial APIs, and LLM-powered summarization.

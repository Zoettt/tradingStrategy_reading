<objective>
Create SummarizationService that generates structured business summaries for stocks using LLM. Takes StockInfo (from Phase 1-2) + EarningsData + company_overview, returns StockSummary with JSON output.

Purpose: Transform raw financial data into readable business intelligence summaries with hallucination-reducing context.
Output: SummarizationService that produces StockSummary JSON per stock.
</objective>

<context>
@src/fris/models.py (Phase 1 - StockInfo, Phase 2 - EarningsData, QuarterlyData)
@src/fris/earnings_service.py (Phase 2 - get_earnings_data(), get_company_overview())
@src/fris/service.py (Phase 1 - TopicSearchService orchestrates the pipeline)

# Existing data models available:
- StockInfo: ticker, company_name, sector, industry, market_cap, current_price, pe_ratio, pb_ratio, description
- EarningsData: ticker, earnings_date, eps_current, eps_forward, revenue, revenue_yoy_change, data_source, fetched_at
- QuarterlyData: ticker, quarter, year, eps, revenue, revenue_yoy_change

# Phase 2 established:
- EarningsService.get_earnings_data(ticker) -> EarningsData
- EarningsService.get_company_overview(ticker) -> dict
- Data freshness via fetched_at timestamp (FRIS-25)

# LLM Integration (per user context):
- OpenAI GPT-4o-mini as default (cost efficient)
- Support Anthropic Claude as alternative
- Structured output format (JSON)
</context>

    Create src/fris/summarization_service.py:

    1. SummarizationService class:
       - __init__(self, llm_client: Optional[LLMClient] = None, earnings_service: Optional[EarningsService] = None)
         * Creates LLMClient(OPENAI, "gpt-4o-mini") if None
         * Creates EarningsService() if None

       - summarize(self, stock_info: StockInfo, include_quarters: bool = False) -> StockSummary:
         * Fetches earnings_data via self._earnings_service.get_earnings_data(stock_info.ticker)
         * Fetches company_overview via self._earnings_service.get_company_overview(stock_info.ticker)
         * Builds financial context via LLMClient._build_financial_context()

         * Calls LLM to generate summary_text
         * Builds key_metrics dict from earnings_data and overview
         * Sets data_sources to ["yfinance"]
         * Sets generated_at to current ISO timestamp
         * Returns StockSummary

       - summarize_batch(self, stocks: list[StockInfo]) -> list[StockSummary]:
         * Calls summarize() for each stock in list
         * Returns list of StockSummary (FRIS-16: each summary is separate document)

    2. Reporting period determination:
       - Use earnings_data.earnings_date to determine period
       - Format as "Q1/Q2/Q3/Q4 YYYY" or "FY YYYY"

    3. Error handling (FRIS-18 context):
       - If LLM call fails, return StockSummary with summary_text="Summary generation failed" and error details
       - If earnings data unavailable, still generate summary with available info

    4. FRIS-19 (cite data sources):
       - Always include "data_source: yfinance" in data_sources list
       - Prompt instructs LLM to reference data sources in summary

    5. FRIS-25 (data freshness):
       - Use earnings_data.fetched_at for data freshness indication
       - Set generated_at on summary to when LLM generated it

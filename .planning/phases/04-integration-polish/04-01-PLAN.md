```python
class PipelineResult:
    summaries: list[StockSummary]
    failed_tickers: list[str]  # Tickers that failed with error messages
    total_count: int
    success_count: int
    error_count: int
```

2. FRISPipeline class with __init__ taking optional service instances

3. run(topic: str, time_period: TimePeriod, criteria: FilterCriteria) -> PipelineResult:
   - Calls TopicSearchService.search(topic, time_period)
   - Calls StockFilterService.apply_filters(criteria, stocks)
   - For each filtered stock:
     - Try SummarizationService.summarize(stock) -> StockSummary
     - On exception: log error, add ticker to failed_tickers, continue
   - Returns PipelineResult with all summaries + failed tickers

4. run_batch(topic: str, time_period: TimePeriod, criteria_list: list[FilterCriteria]) -> list[PipelineResult]:
   - Run pipeline with different filter criteria
   - Return list of PipelineResult

5. Data freshness: All summaries already have generated_at from SummarizationService. EarningsData has fetched_at. These propagate through.

Do NOT use global state or singletons. Accept services via __init__ for testability.

```python
@app.post("/analyze")
def analyze(request: AnalyzeRequest) -> AnalyzeResponse:
    pipeline = FRISPipeline()
    result = pipeline.run(
        topic=request.topic,
        time_period=request.time_period,
        criteria=request.criteria
    )
    return AnalyzeResponse(
        summaries=[s.to_dict() for s in result.summaries],
        failed_tickers=result.failed_tickers,
        total_count=result.total_count,
        success_count=result.success_count,
        error_count=result.error_count
    )
```
